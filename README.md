# 🛒 Amazon Landing Page Clone

A fully responsive **Amazon landing page clone** built using **HTML, CSS, and JavaScript** to replicate the look and feel of the real Amazon homepage.  
This project focuses on front-end design, layout accuracy, responsive structure, and smooth hover interactions to deliver a professional e-commerce UI experience.

---

## 🚀 Features

- 🧭 **Realistic UI Design**
  - Replicates Amazon’s homepage with navigation bar, product cards, hero banner, and footer.
  - Includes sections like Today’s Deals, Shop by Category, and Sign-In options.

- 📱 **Fully Responsive Layout**
  - Adapts seamlessly to mobile, tablet, and desktop screens.
  - Uses CSS Flexbox and Grid for layout management.

- 🎨 **Interactive Elements**
  - Hover effects for buttons and links.
  - Dynamic product category highlighting.
  - Animated banner transitions using CSS.

- ⚙️ **Optimized Performance**
  - Lightweight and fast-loading.
  - Clean, semantic HTML structure for accessibility and SEO.

- 🧩 **Easy to Customize**
  - Modular CSS and JS files for adding new sections or styles.
